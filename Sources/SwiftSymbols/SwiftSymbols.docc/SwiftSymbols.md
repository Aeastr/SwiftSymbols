# ``SwiftSymbols``

Browse, search and select SF Symbols with a styleable SwiftUI grid.

@Metadata {
    @TopicsVisualStyle(detailedGrid)
}

## Overview

Load the catalog through `SymbolIndex`, filter it for the current system, then display flat results or categorized sections. The host supplies scrolling, navigation and selection storage. The Foundation-only SwiftSymbolsIndex product owns catalog decoding and search.
